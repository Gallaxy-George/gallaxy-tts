# Gallaxy Icon Composer Starter Layers

Import these files into Icon Composer as separate layers, in this order:

1. `background.svg`
2. `g-mark.svg`
3. `red-dot.svg`

All three files use the same 1024 x 1024 canvas, so they should align when stacked.

`combined-preview.svg` is only for previewing the full mark outside Icon Composer.
